# trompe-l'oeil

The zdesign studio site.

Static HTML with GSAP-driven motion. No build step, no dependencies to install — clone the repo and open `index.html` in a browser.

```
index.html      page markup
assets/         main.css, main.js, inline graphics
fonts/          webfonts and the type/color layer (tromploy.css)
img/            photography, cutouts, and video loops
```
